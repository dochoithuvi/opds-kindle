# OPDS Library v0.2.2

## What's new

- Hides the built-in OPDS URL from the Kindle interface and displays it simply as **Kho sách mặc định**.
- Adds **+ THÊM KHO** for custom OPDS sources.
- Tap a catalog name to select it and open it immediately.
- Adds **SỬA / XÓA** for custom catalogs.
- Remembers custom catalogs and the selected source in documents/OPDSLibrary/catalogs.json.
- If the selected custom catalog is deleted, OPDS Library automatically falls back to the built-in catalog.
- Keeps search, page filtering, large paging buttons, MOBI/AZW3/PDF/TXT downloads, and EPUB downloads for KOReader from v0.2.1.
- Keeps **by Dochoithuvi** in the UI.

## Tested target

Kindle Basic 2022 — firmware 5.19.2.

Other Kindle models/firmware versions may behave differently.

## Install

Download Kindle-OPDS-Library-0.2.2-FULL-with-icon.zip from this Release, extract it, then copy the contents of COPY_TO_KINDLE_ROOT to the Kindle USB root.
