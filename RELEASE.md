# OPDS Library v0.2.3

## What's new

- Changes the visible UI credit to **By Maydocsach.gitbook.io**.
- Keeps the v0.2.2 hidden-default catalog manager unchanged.
- Keeps **+ THÊM KHO**, **SỬA / XÓA**, persistent `catalogs.json`, full-catalog search, page filtering, and large paging controls.
- Keeps MOBI/AZW3/PDF/TXT downloads and EPUB downloads for KOReader.
- Release workflow now checks JavaScript syntax, parses `config.xml`, runs `go test` + `go vet`, cross-builds ARMv5/ARMv7, and verifies the ZIP before publishing.

## Tested target

Kindle Basic 2022 — firmware 5.19.2.

Other Kindle models/firmware versions may behave differently.

## Install

Download `Kindle-OPDS-Library-0.2.3-FULL-with-icon.zip` from this Release, extract it, then copy the contents of `COPY_TO_KINDLE_ROOT` to the Kindle USB root.
